# Social Media Scraper

## Android uygulaması

X (Twitter) hesaplarının gönderilerini çeken Android uygulaması [`android/`](android/) klasöründe.
Kurulum ve ayrıntılar için [android/README.md](android/README.md) dosyasına bakın.

## Python betiği (eski)

`main.py`, projenin ilk sürümüdür: Playwright ile X profillerini tarayıp yeni gönderileri e-postayla bildirir.
Artık GitHub Actions ile zamanlanmış olarak çalışmıyor ve X'in giriş duvarı nedeniyle gönderi bulamayabilir.
Güncel ve çalışan sürüm Android uygulamasıdır.
